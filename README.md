## Overview

**Ryzen UI** is a UI library built for Luau, designed to make creating and customising interfaces more convenient.

Its component-based approach lets you organise interface elements into reusable building blocks, keeping UI code easier to maintain and extend.

## Features

- **Custom components** — Build interfaces using reusable UI elements.
- **Customisation** — Adapt components to suit your own interface and styling.
- **Lightweight design** — A focused library without unnecessary complexity.
- **Reusable structure** — Keep interface code organised across your projects.

## Getting Started

### Requirements

- A Luau-compatible environment.
- The Ryzen UI source files.

### Installation

Clone the repository:

```bash
git clone https://github.com/jinxware00/RyzenUI.git
```

Alternatively, download the repository directly from GitHub and add the library to your project.

### Example

Check [`Example.lua`](https://github.com/jinxware00/RyzenUI/blob/main/Example.lua) for an example of how to use Ryzen UI.

The example file is the best place to start when exploring the library's API and available components.
